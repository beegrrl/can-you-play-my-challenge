# House rules

One Offensively Orange Room is a starter-home build challenge for The Sims 4. I wrote it for this test.

| # | Rule | When I say it |
|---|---|---|
| 1 | Each player gets §20,000. | Opening prompt |
| 2 | Base game only. | Opening prompt |
| 3 | Exactly 1 room is offensively orange. The next host picks the color. | Opening prompt |
| 4 | No money cheats. | Added mid-chat |
| 5 | It's a 60-minute speed build. | Added mid-chat |

§ is the game's money sign.

## What is fixed and what is left open

- Rules 1, 4 and 5 are fixed in every case.
- Rule 2 is fixed in cases 1 and 2. In case 3 I leave the packs to whoever hosts.
- Rule 3 fixes the 1 room. The color belongs to the next host, and what counts as offensive is the players' call.

## The 3 cases

I make the challenge 3 times. The conversations differ by 1 move.

- **Case 1, nothing changes.** The opening prompt, then rules 4 and 5.
- **Case 2, the budget drops.** The opening prompt, then rule 4, then a new budget of §16,000, then rule 5.
- **Case 3, the host decides.** The opening prompt leaves the packs to whoever hosts. Then rules 4 and 5.
