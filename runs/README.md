# How the 9 runs were saved

All 9 ran on November 25, 2026, from 12:30 to 12:45 a.m. Pacific, in Muse on the web. The second account was opened the same night and had never been sent the challenge.

Each run is 1 message in a new side chat. The message is a file from `handoffs/`, pasted whole.

## The order matters

The runs went in this order: c1-A, c1-B, c1-C, c2-A, c2-B, c2-C, c3-A, c3-B, c3-C.

Muse's memory belongs to the account, so each new chat arrived knowing the earlier ones. The saved text shows it in 3 places.

- `c2-A.txt` was handed the opening prompt alone, which never mentions a time limit. Its list has the 60-minute rule in the same words as `c1-B.txt`.
- `c1-B.txt` to `c2-B.txt` repeat the list in `c1-A.txt` almost line for line, down to the same lot.
- In `c3-A.txt`, Muse offers to lock in a lot and a time limit "like in your earlier draft".

Only `c1-A.txt` is a clean first contact.

## What each file holds

A file starts with 3 lines: the date, the surface and the run. The whole side chat follows, copied as text.

The second player's first name is replaced with a bracketed note. Nothing else is edited.

The copy has 2 quirks, and both come from the page. The first items of a numbered list lose their numbers. The answer buttons Muse offers show up as plain lines at the end.

## Muse asked 4 questions, and none was answered

`c1-A.txt`, `c1-B.txt`, `c3-A.txt` and `c3-B.txt` end with a question. Each one came after a full rule list, so no reply was sent and every run stayed at 1 message. The reply in `challenge/wording.md` was never used.
