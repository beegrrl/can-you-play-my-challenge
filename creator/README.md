# How these 6 files were saved

The 3 chats ran on November 24, 2026, from 11:42 p.m. to midnight Pacific, in Muse for macOS, version 13.1, on the Free plan. Each case had its own side chat, and memory was on.

Each line sent to Muse was pasted from `challenge/wording.md`, so the chats match the frozen wording character for character.

## The conversation files

Each `case-N-conversation.txt` is the whole side chat, copied with Select All. Nothing in it is edited.

The copy has 2 quirks, and both come from the app.

- A card shows up as its title alone. The working page Muse built stays in the app.
- The labels change partway down. Early turns read "User message:" and "Assistant message:". Later turns read "You:", and Muse's answers carry no label.

Case 1 opens with Muse recalling the sock drawer card described in `step0-notes.md`. That is the account's memory at work, and it stays in the file.

## The card files

Each `case-N-card.txt` is the plain-text card from the end of that chat, taken with the copy button on Muse's text block. It matches the last block of the conversation file.

## Muse asked 1 question, and it went unanswered

In case 2, Muse asked whether the lower budget should be a spending limit or a cheat that sets the funds. The frozen wording has no line for that, so the next rule went in and the question was left alone. Muse kept the spending limit.
