Starter-Home Build Challenge — The Sims 4
Created by Melissa

Goal: Build a livable starter home in 60 minutes, for §20,000, with exactly one offensively orange room.

Fixed rules:
- 60-minute speed build — build stops when the timer ends.
- Budget: §20,000 total, house + furnishings.
- No money cheats — no motherlode, rosebud, kaching, or money X. Start fresh at §20,000.
- Packs: Whoever hosts picks which packs are allowed.
- Exactly one room offensively orange — no more, no less.
- Next round: The next host picks the color.

Choices left to the host:
- Lot: Which lot everyone builds on.
- Packs allowed this round: You pick them.
- Voting: How you vote on livability, budget, and orange commitment.
- Next host: Winner hosts next, or rotation — you decide.
- Proof: Screenshots, tour, or live walkthrough.
